# \# Personal Voice Assistant

# 

# A Python-based personal voice assistant using speech recognition and text-to-speech.

# 

# \## Features

# \- Speech-to-text via Google Speech API

# \- Text-to-speech via pyttsx3

# \- Voice commands: time, date, web search, open apps

# 

# \## Requirements

# \- Python 3.14

# \- realme Buds or any headset with mic

# 

# \## Installation

# pip install -r requirements.txt

# 

# \## Run

# python src/main.py

# 

# \## Sample Commands

# \- "Hello" → Greets you

# \- "What time is it" → Tells time

# \- "What is the date" → Tells date

# \- "Search Python tutorials" → Opens Google

# \- "Open YouTube" → Opens YouTube

# \- "Open Notepad" → Opens Notepad

# \- "Stop" or "Bye" → Exits assistant
